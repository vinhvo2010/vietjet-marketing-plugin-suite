# Prompt and QA Template

## Prompt Package

```text
CREATIVE OBJECTIVE:
[What the asset should communicate visually]

FACTUAL CAMPAIGN REQUIREMENTS:
[Only supplied or approved facts]

CREATIVE DIRECTION:
[Scene, composition, lighting, motion, mood, visual hierarchy]

LOCKS:
[Aircraft / livery / mascot / face / typography / text / logo / color constraints]

FORMAT:
[Aspect ratio, duration, resolution, channel, series position]

NEGATIVE PROMPT / PROHIBITIONS:
[Wrong model, altered identity, invented text, extra logos, subtitles, artifacts, etc.]

MANUAL DESIGN ACTIONS:
[Text/logo/legal line to add manually]
```

## QA Status

Use:

- `PASS`: requirement is visibly satisfied.
- `FAIL`: requirement is visibly violated.
- `NOT VERIFIABLE`: required reference or evidence is unavailable.
- `NOT APPLICABLE`: requirement does not apply.
