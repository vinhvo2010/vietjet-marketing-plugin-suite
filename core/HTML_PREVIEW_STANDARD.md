# HTML Preview Standard

## Concept And Release Modes

- Concept mode must visibly show `CONCEPT PREVIEW — NOT PRODUCTION READY`.
- Release mode may only be enabled after the evidence-backed release gate is complete.
- Concept mode may display draft assets only when every visual is labeled as draft and human-QA-required.
- Release mode may load assets only from `assets/release/`.

## Numbers And Copy Safety

- Assumption-only numbers must be labeled `ASSUMPTION ONLY — NOT FORECAST`.
- Scenario displays must use `Planning Scenario — Assumptions Only`, never validated business-case language.
- Clipboard summaries must not copy unverified bookings, revenue, ABV, ROI, fare, inventory, or performance numbers.
- Any copied summary must state that all numbers are assumptions only and are not approved targets or forecasts.

## Required Panels

- Concept/release state banner
- Governance warning
- Release blocker panel
- Draft asset status labels
